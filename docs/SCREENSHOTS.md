## Settings

The settings panel keeps connection paths, stage timing, display choices, local history, and the
less common transport controls in one responsive surface.

<img src="assets/settings.png" alt="Graphite Meter settings panel beside a completed measurement" width="920">

## Endpoint information

Endpoint information reports the selected throughput and latency paths and separates browser and
server protocol evidence where both are available.

<img src="assets/endpoint.png" alt="Graphite Meter endpoint information panel beside a completed measurement" width="920">

## Result history

Optional device-local history presents sortable completed summaries and the selected run without
changing or interrupting the live meter.
