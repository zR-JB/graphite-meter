# Graphite Meter HTTP route pin, shared by the Rust workspace and the browser client.
#
# Format (one route per non-comment, non-blank line):
#   <name> | <path> | <kind>
#
#   name = the key every implementation uses for the route
#   path = the exact path the server mounts and the client requests
#   kind = http | ws | wt | auth, the transport that reaches the route. A wt
#          route is an HTTP/3 extended-CONNECT session; under authentication it
#          carries a bearer grant or a single-use token minted at /wt/session.
#          An auth route is a sign-in route, answered at the public HTTPS origin
#          only while authentication is on.
#
# Routes are never transmitted: preflight advertises origins and transports only,
# so each site carries its own table and this file keeps the tables identical.
# Every route test loads THIS file as its fixture:
#   Rust: rust/proto/tests/codes.rs (proto::route Route and AuthRoute)
#   TS:   client/src/protocol/pins.test.ts (protocol/routes.ts ROUTES and AUTH_ROUTES)
#
