# Graphite Meter failure reason pin, shared by the Rust workspace and the browser client.
#
# Format (one reason per non-comment, non-blank line):
#   <reason> | <label>
#
#   reason = the key every implementation uses for the failure
#   label  = the text every view shows for it
#
# Read by rust/proto/tests/codes.rs and client/src/protocol/pins.test.ts.

path-failed | Path unavailable
connection-lost | Connection lost
timeout | Stopped delivering data
sign-in-required | Sign-in required
client-limit | Limit reached for your address or sign-in
server-capacity | Server at capacity
protocol-error | Unexpected server response
insufficient-evidence | Too little measured time
