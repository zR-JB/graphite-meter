# Graphite Meter — wire-protocol conformance corpus (shared across Go / TS / Rust).
#
# Format (one test per non-comment, non-blank line):
#   <dir> | <input> | <expected>
#
#   dir      = "encode" | "decode"
#   For decode: <input> is the on-wire string; <expected> is a canonical
#               key=value;... rendering of the parsed frame (op=..., plus args),
#               or "ERR:<code>" when the input must be rejected.
#   For encode: <input> is a canonical op=...;arg=... spec; <expected> is the
#               exact on-wire string the encoder must produce.
#
# Opcodes and semantics are defined in api/wire.md. The rows below are the
# happy-path + boundary set for every channel. Every implementation's wire test
# loads THIS file as its fixture.
