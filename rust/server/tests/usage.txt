Usage: graphite-meter-server [options]
       graphite-meter-server <command>

Commands:
  version, --version  Print the version
  hash-password       Read a password twice on stdin and print its Argon2id hash
  healthcheck         Exit 0 when this configuration's clear listener answers /probe within 2 s
  --legal             Print the reviewed project and dependency notices

Options:
  --h1-addr <address>                            Clear HTTP/1.1 listen address (env: GM_H1_ADDR) (default: :7246)
  --h1-tls-addr <address>                        HTTPS HTTP/1.1 listen address; empty disables it (env: GM_H1_TLS_ADDR)
  --h2-addr <address>                            HTTP/2 TLS listen address; empty disables it (env: GM_H2_ADDR)
  --h3-addr <address>                            HTTP/3 UDP and bootstrap TCP listen address; empty disables it (env: GM_H3_ADDR)
  --tls-cert <path>                              TLS certificate PEM path (env: GM_TLS_CERT)
  --tls-key <path>                               TLS private key PEM path (env: GM_TLS_KEY)
  --h1-public-origin <origin>                    Public origin of the native clear HTTP/1.1 listener (env: GM_H1_PUBLIC_ORIGIN)
  --h1-tls-public-origin <origin>                Public origin of the native HTTPS HTTP/1.1 listener (env: GM_H1_TLS_PUBLIC_ORIGIN)
  --h2-public-origin <origin>                    Public origin of the native HTTP/2 listener (env: GM_H2_PUBLIC_ORIGIN)
  --h3-public-origin <origin>                    Public origin of the native HTTP/3 listener (env: GM_H3_PUBLIC_ORIGIN)
  --advertised-native-endpoints <names>          all, none, or comma-separated http1-clear, http1-tls, http2, http3 (env: GM_ADVERTISED_NATIVE_ENDPOINTS) (default: all)
  --public-origins <origins>                     Comma-separated negotiated origins providing throughput and latency (env: GM_PUBLIC_ORIGINS)
  --public-throughput-origins <origins>          Comma-separated negotiated throughput origins (env: GM_PUBLIC_THROUGHPUT_ORIGINS)
  --public-latency-origins <origins>             Comma-separated WebSocket latency origins (env: GM_PUBLIC_LATENCY_ORIGINS)
  --name <name>                                  Server name advertised in /preflight (env: GM_SERVER_NAME) (default: graphite-meter)
  --location <location>                          Server location label (env: GM_SERVER_LOCATION)
  --result-history-default                       Save completed browser results on this device by default (env: GM_RESULT_HISTORY_DEFAULT)
  --verbose                                      Log throughput every second, admission counters every 30s and sign-in debug lines (env: GM_VERBOSE)
  --max-active-measurements <number>             Measurements running at once: downloads, uploads, latency connections and WebTransport sessions (env: GM_MAX_ACTIVE_MEASUREMENTS) (default: 256)
  --max-active-measurements-per-client <number>  Measurements running at once per client (env: GM_MAX_ACTIVE_MEASUREMENTS_PER_CLIENT) (default: 32)
  --max-active-sessions <number>                 WebTransport sessions running at once, which also count as measurements (env: GM_MAX_ACTIVE_SESSIONS) (default: 64)
  --max-sessions-per-client <number>             WebTransport sessions running at once per client (env: GM_MAX_SESSIONS_PER_CLIENT) (default: 8)
  --max-buffer-bytes <bytes>                     Bytes of connection buffers shared by QUIC and HTTP/2 (env: GM_MAX_BUFFER_BYTES) (default: 8589934592)
  --max-connections <number>                     TCP and QUIC connections open at once (env: GM_MAX_CONNECTIONS) (default: 4096)
  --max-connections-per-client <number>          Connections open at once per direct client (env: GM_MAX_CONNECTIONS_PER_CLIENT) (default: 64)
  --max-operation-duration <duration>            Longest HTTP download or upload and longest latency connection; unset, at least the stage limit plus 1m (env: GM_MAX_OPERATION_DURATION) (default: 6m)
  --max-session-duration <duration>              Longest WebTransport download or upload session; unset, at least the operation lifetime (env: GM_MAX_SESSION_DURATION) (default: 2h)
  --max-stage-duration <duration>                Longest stage clients may plan, 1s to 24h (env: GM_MAX_STAGE_DURATION) (default: 5m)
  --auth-mode <mode>                             Authentication mode: off, password, oidc, or hybrid (env: GM_AUTH_MODE) (default: off)
  --auth-public-url <origin>                     Canonical HTTPS UI origin (env: GM_AUTH_PUBLIC_URL)
  --auth-password-hash-file <file>               File containing the operator Argon2id PHC hash (env: GM_AUTH_PASSWORD_HASH_FILE)
  --auth-oidc-issuer <url>                       OIDC issuer URL (env: GM_AUTH_OIDC_ISSUER)
  --auth-oidc-client-id <id>                     OIDC client ID (env: GM_AUTH_OIDC_CLIENT_ID)
  --auth-oidc-client-secret-file <file>          File containing the OIDC client secret (env: GM_AUTH_OIDC_CLIENT_SECRET_FILE)
  --auth-oidc-allowed-groups <groups>            Comma-separated case-sensitive OIDC groups (env: GM_AUTH_OIDC_ALLOWED_GROUPS)
  --auth-oidc-provider-name <label>              OIDC provider label (env: GM_AUTH_OIDC_PROVIDER_NAME) (default: Authelia)

Environment only:
  GM_TRUSTED_PROXIES                 Proxy CIDRs allowed to supply X-Real-IP, X-Forwarded-Proto and X-Forwarded-Host
  GM_AUTH_PASSWORD_HASH              Inline operator Argon2id PHC hash; prefer the file
  GM_AUTH_OIDC_CLIENT_SECRET         Inline OIDC client secret; prefer the file
  GM_SERVER_CATALOG                  Server catalog JSON
  GM_SERVER_CATALOG_FILE             Absolute path of a server catalog JSON file
  TZ                                 Time zone name for log times, such as Europe/Berlin (default: UTC)
  HTTPS_PROXY, HTTP_PROXY, NO_PROXY  Proxy for OIDC requests
  SSL_CERT_FILE, SSL_CERT_DIR        CA roots for OIDC requests (default: the system's)
  TOKIO_WORKER_THREADS               Runtime worker threads (default: one per CPU)
